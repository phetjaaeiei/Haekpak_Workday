# ฟอร์มเลือกวันทำงานร้านชาบู

เว็บตัวอย่างสำหรับให้พนักงานกรอกชื่อเล่น เลือกตำแหน่ง และเลือกวันทำงาน 3 วันต่อสัปดาห์ พร้อมหน้า Admin สำหรับดูตารางรวมทุกตำแหน่ง

## วิธีรัน

```powershell
node server.js
```

จากนั้นเปิด `http://localhost:3000`

## เงื่อนไขที่ตั้งไว้

- พนักงานแต่ละคนเลือกได้ 3 วันต่อสัปดาห์
- พนักงานเสิร์ฟรับได้ 4 คนต่อวัน
- พนักงานล้างจานรับได้ 2 คนต่อวัน
- พนักงานสไลด์หมูรับได้ 1 คนต่อวัน
- พนักงานเตรียมของรับได้ 3 คนต่อวัน
- ข้อมูลถูกเก็บไว้ที่ `data/schedules.json`
